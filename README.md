# Arduino-DC-Motor-Speed-Controller
An Arduino-based DC motor controlled using PWM

The aim of this project is to control the speed of a DC motor using the coding on an Arduino and a potentiometer
The potentiometer provides an adjustable input, the Arduino converts this into a PWM signal. The motor driver uses this PWM signal to control the power delivered to the motor.

Components: Arduino Uno R3, 3V DC Motor, L293D IC Motor Driver, Potentiometer, Breadboard and Jumper Wires

Control software written in Arduino C++
